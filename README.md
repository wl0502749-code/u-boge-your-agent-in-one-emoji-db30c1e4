One emoji that stands for my AI agent: 🦾 — a mechanical arm. An agent is not a face that chats; it is a hand that does the work. It builds, fixes, reaches for tools and acts on its own, with no explanation needed. The program writes that single glyph to `/output/entry.txt` and nothing else.

## Run it

```sh
python3 main.py
```
